## 🚀 GitHub Pages Deployment

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Rebuild website with modern responsive UI"
   git push origin main
   ```
2. In your GitHub repository settings:
   - Navigate to **Settings** &rarr; **Pages**.
   - Under **Build and deployment** &rarr; **Source**, select **Deploy from a branch**.
   - Select branch: `main` (or `master`) and folder: `/ (root)`.
   - Click **Save**.
3. Your website will be live in seconds at `https://<username>.github.io/<repo-name>/`.
